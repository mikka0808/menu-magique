Menu Magique

Organisez vos repas de la semaine, midi et soir, directement depuis votre iPhone.

Bibliothèque de recettes

Ajoutez vos idées de repas pour les réutiliser facilement. Elles s'ajoutent aux suggestions déjà présentes dans l'application.

Conseils d'utilisation

  • Tapez directement dans les cases pour saisir vos repas.
  • Glissez-déposez un repas sur un autre jour pour le déplacer ou l'échanger rapidement.
  • Utilisez le bouton Suggestion pour choisir une idée dans la bibliothèque.
  • Le plan est sauvegardé automatiquement sur votre appareil. Vous pouvez donc l'utiliser hors connexion.
  • Ajoutez cette page à votre écran d'accueil pour une expérience plus proche d'une application.
